# Aqua Tracker 💧

Prototipo web inspirado en el boceto de Aqua Tracker. Está desarrollado con HTML, CSS y JavaScript puro, por lo que no requiere instalar dependencias.

## Cómo abrirlo en Visual Studio Code

1. Descarga y descomprime `aqua_tracker.zip`.
2. Abre Visual Studio Code.
3. Selecciona **Archivo → Abrir carpeta...** y abre la carpeta `aqua_tracker`.
4. Abre `index.html` en el navegador. También puedes instalar la extensión **Live Server**, hacer clic derecho sobre `index.html` y elegir **Open with Live Server**.

## Funcionalidades

- Agregar tareas con nombre, categoría y litros estimados.
- Marcar tareas como completadas o pendientes.
- Filtrar todas las tareas, las pendientes o las completadas.
- Editar y eliminar tareas.
- Resumen de tareas completadas, progreso y litros estimados.
- Consejos para ahorrar agua.
- Guardado local en el navegador mediante `localStorage`.
- Diseño adaptable a celulares, tabletas y computadores.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: diseño visual y adaptación a pantallas.
- `script.js`: interacciones y almacenamiento de tareas.

**Nota:** Los litros son estimaciones ingresadas por quien usa la aplicación; el resumen es orientativo y no representa una medición real del consumo de agua.
